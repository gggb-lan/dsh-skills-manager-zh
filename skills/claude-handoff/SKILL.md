---
name: claude-handoff
description: 把当前对话交给一个立刻接手的全新后台代理。
argument-hint: "下一个会话要用来做什么？"
disable-model-invocation: true
---

写一份当前对话的交接摘要，让全新代理能继续工作。存到用户操作系统的临时目录，然后启动一个以它为 prompt 的后台代理：`claude --bg --name "<描述性名字>" -- "$(cat <摘要文件>)"`。传文件能避免 shell 执行摘要里的反引号或展开 `$`。它从当前工作目录启动并立即返回；用户用 `claude agents` 管理它。

始终传 `-n`/`--name` 并给描述性名字（例如 `--name "Fix login bug"`）；它设置任务列表、会话选择器和终端标题里显示的名称。

摘要里加一节“建议使用的技能”，写明下一个代理应该调用哪些技能。

不要重复已经记录在其他产物里的内容（规格、计划、ADR、issue、commit、diff）。用路径或 URL 引用它们。

对敏感信息脱敏：API key、密码、个人身份信息——因为摘要会成为代理的 prompt。

如果用户传了参数，把它当作“下一个会话要聚焦什么”的描述，据此裁剪摘要。
