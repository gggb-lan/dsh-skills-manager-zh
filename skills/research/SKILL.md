---
name: research
description: 针对高可信一手来源调查一个问题，并把发现写成仓库里的 Markdown 文件。当用户想调研某个主题、收集文档或 API 事实，或把阅读工作交给后台代理时使用。
---

起一个**后台代理**去做调研，这样它阅读时你还能继续工作。

它的任务：

1. 针对**一手来源**（官方文档、源代码、规格、第一方 API）调查这个问题，而不是别人对它们的二手转述。每一条结论都要追回到拥有它的原始来源。
2. 把发现写进单个 Markdown 文件，每条结论标注来源。
3. 存到仓库已经在存放这类笔记的位置；沿用既有约定。如果没有约定，放到一个合理的位置，并说明放在哪。
